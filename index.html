Domain-enum: Automated Recon Pipeline

Open Source Tool
Challenge

The passive reconnaissance phase of penetration tests was slow and manual — requiring multiple tools chained by hand, introducing coverage gaps and inconsistency across engagements.

Solution

Built Domain-enum: a single automated script that chains specialized subdomain discovery tools, crawls URLs for vulnerabilities like LFI and Open Redirects, and scans infrastructure for misconfigurations — condensing hours of manual work into minutes.

✓ Automates the transition from a single domain to a comprehensive attack surface map — consistently, repeatably, and at scale.
